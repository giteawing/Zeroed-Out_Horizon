# Контент, UI и графика

## Контент как данные

- `src/content/texts.json` — подписи, кнопки, новости, подсказки, названия
  групп и пользовательские сообщения.
- `src/content/upgrades.json` — покупки: `id`, `tab`, `group`, `name`,
  `description`, `icon`, `type`, `baseCost`, уровни и `effect`.
- `src/content/config.json` — игровые числа, правила каналов, налоги, время,
  победа и другие параметры.
- `src/content/achievements.json` — условия достижений.
- `src/content/credits.txt` — текст финальных титров, который предоставляется
  владельцем; не сочиняй и не вставляй защищённый текст по памяти.

Не добавляй русские строки интерфейса в `src/ui/` или `src/main.ts`.
Добавляй ключ в JSON, используй типизированный accessor `texts.get()` и
проверяй `tests/content.test.ts`. Исключения допустимы для технических
идентификаторов, комментариев и диагностических сообщений разработчика.

## Магазин и HUD

- Магазин должен использовать результаты ядра для цены, количества покупки,
  доступности, причины блокировки и максимального уровня. Не повторяй эти
  формулы в UI.
- Все покупки выбранной вкладки остаются видимыми; недоступные показываются
  заблокированными и с причиной блокировки.
- Пакетная покупка должна передавать количество в ядро и показывать фактическую
  стоимость/число уровней, а не только менять подпись кнопки.
- HUD отображает фактическую выручку и расходы, а не теоретическую мощность
  каналов. Товарные, денежные и имущественные показатели должны быть
  согласованы с `DerivedStats`.
- Проверяй длинные подписи, переносы, переполнение и доступность клавиатуры.
  Страница desktop-only; прокрутка и размеры проверяются DOM/E2E тестами.

## SVG и генераторы

- Единый стиль: пастель-нуар, нефтяной фон, золото, малиновый и зелёный
  акценты; основная палитра задаётся CSS variables в
  `src/styles/base.css`.
- Иконки используют квадратный `viewBox`, толстую тёмную обводку и
  читаемую форму в малом размере.
- `npm run art` запускает `scripts/generate-icons.mjs` и
  `scripts/generate-scenes.mjs`. Изменение шаблонов обычно требует проверки
  файлов в `scripts/lib/art.mjs` и визуального просмотра итоговых SVG.
- Иконки: по умолчанию генератор создаёт только недостающие файлы.
  `npm run art:force` перезаписывает иконки из словаря `icons` и стирает их
  ручные правки; проверь diff и не коммить случайные массовые изменения.
  Рукописные иконки без записи в словаре (`devalue`, `domestic-cartel`,
  `export-cartel`) генератор не трогает никогда.
- Сцены `bg.svg`, `logo.svg`, `finale.svg` собирает только генератор, и
  готовые файлы обязаны побайтно совпадать с `buildScenes()`. Правишь сцену —
  правь `scripts/generate-scenes.mjs` и запускай `npm run art`.
- Примитивы `art.mjs` ссылаются на градиенты иконок (`url(#gold)`); в сценах
  их переводит на `…Grad` таблица `SCENE_GRADIENTS`. Новый градиент в сцене
  добавляй и в `<defs>` сцены, и в эту таблицу.
- Генераторы проверяют результат до записи (`assertSvg`): битая ссылка
  `url(#id)`, `undefined` или `NaN` останавливают запуск. Те же проверки и
  побайтное сравнение сцен выполняет `tests/svg.test.ts`.
- Проверка без записи в `public/images`: `--out <папка>` у обоих генераторов.
- Интерактивная сцена долота и файл `public/images/drill.svg` удалены вместе
  с механикой ручной добычи. Не восстанавливай их в приложении или генераторах.
- Иконка покупки должна соответствовать `icon`/id в контенте; целостность
  проверяет content test.

## Звук

Звук реализован синтезом через Web Audio API в `src/audio/sound.ts`.
Соблюдай browser autoplay policy: создание/возобновление AudioContext должно
происходить из пользовательского жеста. Состояние mute хранится в сейве;
не создавай отдельные аудиофайлы без необходимости и проверки лицензии.
