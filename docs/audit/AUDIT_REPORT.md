## Резюме

Работоспособная небольшая клиентская игра с относительно хорошо отделённым от DOM экономическим ядром, богатой регрессионной базой и воспроизводимыми ботами. Главные долги — перегруженный движок, публичное изменяемое состояние и ручная инвалидация кеша, синхронная работа на главном потоке, слабая проверка альтернативных стратегий. Найдены конкретные расхождения авто-маршрутизации и финансовой оптимальности, потеря видимого времени при длительном кадре и условная ошибка подсказки победы. Баланс на людях, реальная производительность устройств, исчерпывающее отсутствие эксплойтов и корректность всех комбинаций не доказаны.

Сохранить: чистые функции расчёта экономики и единый settlement, раздельные склады, фиксированные подшаги, контролируемый RNG, совместимость сейвов и архив повреждённого сейва, UI с переиспользованием карточек, контент в JSON, регрессионные тесты и CI. `import.meta.env.DEV` скрывает инженерное меню в production (`src/main.ts:195–197`); прежнее предположение о доступности кнопки в production не подтверждается. Однако `window.__game` выставляется без такого условия (`main.ts:548–549`); локальная однопользовательская игра не имеет серверной границы доверия, поэтому это не серверная уязвимость.

## Проверки

Node 22.22.3, `npm ci`: успех; `npm test`: 18 файлов, 277 тестов прошли за 199,68 с; `npm run build`: TypeScript и Vite успешно, JS 223,73 kB / gzip 61,88 kB, CSS 28,21 kB / gzip 6,22 kB. `npm run balance:report`: четыре победы; детали и ограничения в экономическом отчёте. `npm run test:e2e`: 11 из 11 не запустились — отсутствует Playwright Chromium headless shell; это ошибка окружения, а не свидетельство дефекта приложения, E2E фактически не проверены. CI устанавливает браузер; в текущей среде загрузка браузерных бинарников не проверена. `npm audit`: 3 уязвимых пакета (1 moderate, 2 critical), только dev-зависимости: vitest, tinypool, @vitest/mocker; условия эксплуатации не проверялись. Первоначально `npm test` не запускался из-за отсутствующих зависимостей, после `npm ci` прошёл.

## Контроль качества и ограничения

Покрыты economy, state/storage, purchases, детерминизм, DOM happy-dom, сценарии бота и Playwright smoke. Данные покрытия строк не собирались; проход тестов не означает полноту. Интеграционные тесты существуют внутри game/regressions, но браузерный прогон в этой среде не завершён. Длинные сессии сверх сценариев бота, многовкладочность, мобильные устройства, сетевое развёртывание Pages и UX с участием людей не измерены. `tests/e2e/smoke.spec.ts` содержит desktop smoke, не полную матрицу браузеров. Статический обзор не доказывает отсутствие циклов импортов: рекомендована автоматическая проверка границ и циклов.

Успех модернизации: все текущие 277 тестов и E2E в окружении с Chromium проходят; миграция старых сейвов сохраняет экономические инварианты; зафиксированные сценарии имеют согласованные диапазоны баланса; отсутствуют известные применимые уязвимости высокой/критической серьёзности; p95 frame/подшага на зафиксированном устройстве не хуже измеренной базы и укладывается в согласованный бюджет; нет нежелательных изменений текстов/поведения без решения владельца.
