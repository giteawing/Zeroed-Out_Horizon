## 1. Концепт

Браузерная кликер-тапалка в духе Hamster Combat, но **без крипты**, кошельков и внешних сервисов. Игрок тапает по буровой, получает виртуальные монеты **«нефтефаники»**, покупает улучшения и устраивает коррупционные схемы. В конце копит на **Магистральный Насос «Упырь-Абсолют»**. Его покупка даёт победу и финальные титры.

- Тон: сатирический, угарный, в духе «нефтяной империи».
- Длительность прохождения: **15–20 минут** активной игры.
- Платформы: десктоп (мышь) — основная, мобильный браузер — полноценно поддерживается.
- Язык интерфейса: русский.

## 2. Технологический стек

Выбран под простоту агентской разработки и отладки:

- **Vite + TypeScript**, без тяжёлых фреймворков.
- UI на чистом DOM + CSS. Анимации на CSS, частицы на Canvas. Игровой движок не нужен.
- Состояние в одном модуле `state`, главный цикл на `requestAnimationFrame`, экономический `tick` раз в 100 мс.
- Контент в JSON-файлах в `src/content/`.
- Сохранение в `localStorage`, кнопка «Новая игра».
- Тесты: **Vitest** для экономики, **Playwright** для дымового теста прохождения (профили Desktop и Mobile).
- Деплой: GitHub Pages (через GitHub Actions) или любой статический хостинг.
- Звук: Web Audio API (синтез), см. раздел 8.

## 4. Игровой цикл и экран

- **Центр:** большая картинка горизонтальной скважины с шарошечным долотом. По тапу долото вращается и трясётся, летят брызги нефти и всплывающее «+N». Игроку начисляется доход за тап.
- **Сверху:** баланс нефтефаников, **чистый доход в секунду** (доходы минус расходы), прогресс до «Упыря-Абсолюта».
- **Снизу или сбоку:** вкладки «Политические», «Технические», «Роскошь» и список покупок.
- **Лента новостей:** смешные заголовки, реагирующие на события («Император одобрил ваши штаны»).
- Тряска экрана и звуковые эффекты при крупных событиях.

## 5. Экономика

### 5.1. Потоки

- **Постоянные доходы (в секунду):** скважины, нефтепереработка, нефтебазы, АЗС. Улучшения умножают их.
- **Постоянные расходы (в секунду):** налоги (процент от дохода), зарплаты, траты на чиновников. Растут вместе с империей, поэтому игрок снижает их политическими покупками.
- **Доход за тап:** базовое значение, растёт от технических улучшений (долото, насос и т. п.).
- **Одноразовые доходы:** разовые события («пихнуть нефть заграницу», «швырнуть подрядчика»).
- **Одноразовые расходы:** покупки, кризисы, роскошь.

Чистый доход в секунду: `net = gross * (1 - taxRate) - salaries - officials`. Не опускается ниже нуля, чтобы игрок не застрял.

### 5.2. Типы покупок

В `upgrades.json` у каждой покупки есть поле `type`. Реализуются в `core/economy.ts`:

| type | поведение |
|---|---|
| `perTap` | увеличивает доход за тап |
| `passive` | добавляет доход в секунду |
| `multiplier` | множитель дохода (общий или по цепочке) |
| `taxCut` | снижает налоговую ставку |
| `costCut` | снижает расходы (зарплаты, чиновники) |
| `periodic` | раз в N секунд выдаёт бонус (например, новое месторождение) |
| `oneShot` | разовая выплата нефтефаников |
| `gamble` | платишь сразу, через T секунд получаешь в X раз больше |
| `priceBoost` | постоянный множитель цен на нефть и нефтепродукты |
| `luxury` | только трата, даёт ачивку и предмет в «витрине богатства» |

### 5.3. Цены и баланс

- Цена следующего уровня: `cost = baseCost * 1.15^level` (коэффициент в `config.json`).
- У каждой покупки есть `maxLevel` и (по желанию) `unlockAt`: требование по балансу или другой покупке.
- Цена победы лежит в `config.json` (`winCost`). Агент подбирает её скриптом-симулятором так, чтобы активный игрок проходил игру за **15–20 минут**.
- **Обязательно:** в `tests/` симулятор бота, который «играет» (4–6 тапов в секунду, покупает самое выгодное). Тест падает, если прохождение выходит за 12–25 минут. Так баланс подгоняется автоматически.
- Мировая цена нефти плавает по таймеру (±30 %), игрок выбирает момент для «пихнуть нефть заграницу».

### 5.4. Контрольные точки темпа (ориентир)

| Время | Что происходит |
|---|---|
| 0–2 мин | тапы, первые покупки, ощущение «растёт» |
| 2–6 мин | первые пассивы, политические ускорители |
| 6–12 мин | заводы, кризисы, первые крупные события |
| 12–18 мин | роскошь как празднование, подготовка к финалу |
| 18–20 мин | покупка «Упыря-Абсолюта» и титры |

## 6. Контент: покупки и события

Названия, помеченные **«строго»**, обязательны в указанной формулировке. Остальные пункты агент оформляет в том же юморе. Каждая покупка в `upgrades.json` содержит: `id`, `name`, `description` (смешное), `icon`, `type`, `baseCost`, параметры эффекта, `maxLevel`.

### 6.1. «Политические»

1. **«Попросить монет у императора "на поддержание штанов"»** (строго). Разовая выплата, перезарядка.
2. Пойти на фуршет на экономическом форуме. Большой контракт: на время автоматически идёт много монет.
3. Занести в **«министерство нефтяных ресурсов»** (строго). Периодически бесплатно появляются новые месторождения с хорошей нефтеотдачей (`periodic`).
4. Сходить в сауну с главой **«комитета по промышленности»** (строго). Налоги снижаются (`taxCut`).
5. **«Пихнуть нефть заграницу»** (строго). Единовременный большой платёж по мировой цене на нефть.
6. Устроить мировой нефтяной кризис. Дорого, результат ×10 (`gamble`).
7. Устроить экономический форум с икорной вечеринкой. Большой контракт.
8. Отжать месторождение у конкурентов.
9. Отжать нефтеперерабатывающий завод у конкурентов.
10. Устроить топливный кризис. Недорого, но отдача очень большая (`gamble`).
11. Пропихнуть своего человека в правительство. Цены на «мою» нефть и нефтепродукты всегда высокие (`priceBoost`).
12. Пропихнуть своего человека в сенат (законодательный орган). Периодически снижаются налоги.
13. Нагнуть конкурента. Прибыль растёт.
14. Швырнуть подрядчика. Бесплатно, небольшая разовая добавка монет.
15. Оптимизировать зарплату. Снижение издержек (`costCut`).

**Дополнительные идеи (агент реализует 5–8 из них):**

- Подарить борзого щенка депутату.
- Открыть благотворительный фонд (для себя).
- Найти оффшор на Мальдивах.
- Нанять юриста с говорящей фамилией.
- Купить местную газету.
- Пожертвовать на храм (и на уход за храмом).
- Заказать экспертизу, которая доказывает всё.

### 6.2. «Технические»

#### Инфраструктура (сильно увеличивает приток монет)

1. Построить **нефтеперерабатывающий завод**.
2. Построить **нефтебазу**.
3. Построить **сеть АЗС**.
4. Проложить трубопровод **«Чёрная змея»**. Пассивный доход, снижает расходы на логистику.
5. Построить **морской терминал** с собственным танкером. Усиливает «пихнуть нефть заграницу».
6. Построить **железнодорожную эстакаду** для налива цистерн.
7. Построить **газоперерабатывающий завод**. Попутный газ перестаёт сгорать в факеле и превращается в монеты.
8. Построить **электростанцию на попутном газе**. Снижает расходы на электричество.

#### Долота (доход за тап и скорость бурения)

Реальные типы долот по возрастанию эффективности:

1. Лопастное долото. Устаревшее, базовое.
2. Шарошечное с фрезерованными стальными зубьями. Для мягких пород.
3. Шарошечное с твердосплавными вставками (TCI). Для средних и твёрдых пород.
4. Гибридное долото (шарошки + резцы PDC).
5. Долото PDC с резцами из поликристаллического алмаза. Быстрое, износостойкое.
6. Импрегнированное алмазное долото. Для самых твёрдых пород.
7. Финальное **«Долото-Терминатор»**. Юмористическое, выдумка игры.

#### Насосы

- Поршневой буровой насос.
- Усиленный насос высокого давления.
- Насос с цифровым управлением.
- Финальный «Насос-Гигант», который нужен для финальной цели.

#### Каротаж и геология

1. **Улучшенные каротажные приборы** (несколько уровней).
2. **Имиджер** (прибор для получения изображения стенки скважины и измерения угла падения пласта). Подпись: «чтобы красиво видеть пласт и свою зарплату».
3. **Картограф** (программа, которая по резистивиметрии и каротажам лучше изучает пласт, где бурится горизонтальная скважина). Бонус к множителю доходов.
4. **Телеметрия MWD/LWD**. Данные с забоя в реальном времени, множитель к доходу за тап.
5. **Азимутальный резистивиметр**. «Видит» границы пласта вокруг долота, усиливает эффект геонавигатора.
6. **Лаборатория керна**. Открывает бонус «хорошая нефтеотдача» для новых месторождений.

#### Буровое оборудование и технологии

1. **Винтовой забойный двигатель**. Прибавка к доходу за тап.
2. **Роторная управляемая система (РУС)**. Большая прибавка к доходу за тап и к скорости бурения горизонтального участка.
3. **Верхний привод**. Автоматический тап с низкой частотой.
4. **Буровой раствор «Премиум»** (инвертно-эмульсионный). Уменьшает «аварии» и расходы.
5. **Многостадийный ГРП** (гидроразрыв пласта). Мощный множитель пассивного дохода скважин.
6. **«Умная скважина»**. Автоматизация, пассивный доход растёт сам.
7. **Электроцентробежный насос (ЭЦН)**. Увеличивает добычу действующих скважин.

#### Персонал

1. Нанять **геонавигатора**. Монеты прибавляются автоматически.
2. Нанять **ГТИ-шника** (специалист по геолого-технологическим исследованиям). Монеты прибавляются автоматически и больше, чем у геонавигатора.
3. Нанять **буровую бригаду-стахановцев**. Прибавка к доходу за тап, но растут зарплаты.
4. Нанять **главного технолога**. Снижает аварийные расходы.

#### Цифровые и юмористические

1. **Цифровой двойник месторождения**. Множитель ко всему пассивному доходу.
2. **Нейросеть «Пластогадалка»**. Раз в минуту предсказывает «удачное место» и даёт бонус.
3. **Дроны-обходчики**. Снижают расходы на персонал.
4. **Сервисная компания «Рога и Копыта-Сервис»**. Подрядчик-прокладка: приносит доход, но съедает часть в налоги и откаты.
5. **Цех капитального ремонта скважин (КРС)**. Возвращает к жизни «старые» скважины, периодический бонус.
6. **Корпоративный «Единый дашборд»**. Красивые графики вместо реальной работы: небольшой множитель к доходу.

### 6.3. «Роскошь»

Только траты, ничего не увеличивают. Каждая покупка добавляет предмет в «витрину богатства», даёт ачивку и смешную подпись. Все линейки упорядочены по цене и роскошности.

#### Яхты

1. Лодка с мотором.
2. Катер «Нефтяной ручеёк».
3. Яхта «Скважина-1».
4. Суперяхта с вертолётной площадкой.
5. Яхта размером с остров.

#### Машины

1. Подержанная иномарка «для скромных начал».
2. Внедорожник.
3. Лимузин.
4. Раритетный ретро-автомобиль.
5. Бронированный кортеж.

#### Украшения и аксессуары

1. **Брюлики** (несколько уровней: колечко, печатка, ожерелье, корона).
2. **Часы** (от «солидных» до «стоят дороже квартиры»).
3. **Пиджак** (малиновый, как положено; потом золотой, потом «с вышитым гербом империи»).
4. Трость с золотым набалдашником.
5. Шуба из «искусственного» меха (подпись: «исключительно искусственная»).
6. Сигары в позолоченной коробке.

#### Недвижимость

1. **Вилла в Куршевеле** (обязательно).
2. Пентхаус в столице с видом на собственную нефтебазу.
3. Замок с привидениями (оплачивается отдельно).
4. Собственный остров.

#### Транспорт особого класса

1. Вертолёт.
2. Частный самолёт.
3. Ледокол «для рыбалки».
4. Личный дирижабль.

#### Развлечения и прихоти

1. Золотой унитаз.
2. Бассейн с шампанским.
3. Личный повар с «звёздами».
4. Коллекция вин, которую никто не откроет.
5. Икра ложками, на завтрак, обед и ужин.
6. Картина «Чёрный квадрат (копия, но дорогая)».
7. Личный оркестр, играющий «пока ты ешь».
8. Футбольный клуб.
9. Собственный стадион.
10. Памятник самому себе в натуральную величину.
11. Парадный портрет в образе императора.
12. Фонтан, из которого бьёт «нефть» (подпись: «пока только на вид»).
13. Трон с подогревом.
14. Личный Дед Мороз на постоянном окладе.

### 6.4. Финальная цель

**Магистральный Насос «Упырь-Абсолют»** (строго) даёт полный контроль над всей империей. Стоит очень дорого (`winCost`). Покупка доступна только после накопления нужной суммы и, при желании, после покупки нескольких ключевых улучшений. После покупки игра заканчивается полной победой.

## 7. Финал и титры

1. Анимация «насос включается», вся империя дрожит.
2. Короткая катсцена в духе «и вот он, полный контроль».
3. **Титры с прокруткой**, где идёт стихотворение Демьяна Бедного **«Капитал»** (текст в `src/content/credits.txt`) и карикатурная картинка (толстый буржуй в цилиндре купается в монетах) в `public/images/finale.svg`.
4. **Про текст стихотворения:** агент не вставляет его по памяти. Владелец кладёт текст из открытого источника в `credits.txt`. Пока файла нет, показывается текст «Здесь будет стихотворение». Агент обязан добавить в README пункт про это.
5. Кнопки «Играть снова» и «Показать статистику» (время прохождения, число тапов, сумма, потраченная на роскошь).

## 8. Платформы, звук и дизайн

### 8.1. Десктоп + телефон

- **Приоритет:** десктоп с мышью, но мобильный браузер (Chrome Android, Safari iOS) поддерживается полноценно.
- Используй **Pointer Events** (`pointerdown`) вместо `click`: тап срабатывает мгновенно, работает мультитач (несколько пальцев = несколько тапов).
- На кнопке тапа и её контейнере: `touch-action: manipulation`, `user-select: none`, `-webkit-tap-highlight-color: transparent`, чтобы не было зума по двойному тапу и выделения текста.
- В `<head>`: `<meta name="viewport" content="width=device-width, initial-scale=1, viewport-fit=cover">`. Учитывай `env(safe-area-inset-*)`.
- **Раскладка:**
  - Узкий экран (от 360 px): одна колонка. Сверху баланс и доход, в центре скважина, снизу выдвижная панель покупок с вкладками.
  - Широкий экран: скважина по центру или слева, список покупок справа, лента новостей внизу.
- Размеры кликабельных элементов не меньше 44×44 px. Шрифты через `clamp()`.
- Игровой экран без прокрутки страницы, прокручивается только список покупок.
- **Производительность:** частицы и всплывающие цифры ограничены пулом (не больше 40 одновременно), анимации только через `transform` и `opacity`. Цель: 60 fps на среднем телефоне.
- **Фон и сохранение:** при сворачивании вкладки (`visibilitychange`) сохранять игру. При возвращении начислять офлайн-доход (с потолком около 5 минут), чтобы не ломать темп 15–20 минут.
- **Проверка:** в Playwright профили `Desktop Chrome` и `iPhone 13` / `Pixel 7`. Дымовой тест проходит на обоих. Проверку на реальном телефоне через локальную сеть (`vite --host`) записать в AGENTS.md.

### 8.2. Звук

- Звук включается после первого касания (браузеры запрещают автозвук). Кнопка 🔊/🔇 всегда видна, состояние хранится в сохранении.
- **Обязательные звуки:**
  - **Тап:** короткий звук бурения или «дзынь» монеты, 3–4 вариации со случайным небольшим изменением высоты тона, чтобы не надоедало.
  - Покупка (кассовый звук).
  - Крупное событие или кризис (сирена, гудок).
  - Победа (фанфары).
- **Как делать:** синтез через **Web Audio API** (осцилляторы, шум, огибающие): никаких файлов и вопросов с лицензиями. Если синтез звучит плохо, допускаются короткие CC0-звуки в `public/audio/`, тогда источник и лицензия записываются в README.
- **Мобильные нюансы:** `AudioContext` создаётся и `resume()` вызывается внутри первого `pointerdown`. На iOS звук работает только после жеста. Задержка от тапа до звука должна быть незаметной, поэтому не используй тяжёлые `<audio>` на каждый тап.
- В README описать, как заменить звуки.

### 8.3. Дизайн и атмосфера

- Яркая цветная палитра: нефтяной чёрный, золото, малиновый, насыщенный зелёный «деньги».
- Крупные мультяшные иконки, толстые обводки, градиенты. Угарно, но читаемо.
- Анимация бурения: покачивание долота, вращение шарошек, летящие брызги нефти, всплывающие цифры.
- **Новостная лента:** смешные заголовки, меняются по событиям. Минимум 30 строк в `texts.json`.
- **Достижения:** «Первый миллион», «Налоги? Какие налоги?», «Куршевель близко» и так далее.
- Игра должна ощущаться весёлой с первой секунды: яркая заставка с логотипом и кнопкой «Начать бурить».

## 9. Графика: SVG нормального качества

Агент **сам рисует все SVG-иллюстрации** в едином мультяшном стиле. Это финальная графика, а не временные заглушки.

**Единый стиль** (записать в AGENTS.md как «Арт-гайд»):

- Толстая тёмная обводка (3–4 px), плоские заливки с мягким градиентом и бликом, карикатурный стиль.
- Палитра в переменных CSS в одном файле, не больше 8 основных цветов.
- Всё векторное, без растровых вставок. Иконки в квадратном `viewBox`.

**Что нарисовать:**

1. **`drill.svg`** — центральная иконка: горизонтальная скважина в разрезе (пласт с нефтью, труба уходит вбок) и **шарошечное долото** с видимыми шарошками и зубьями. Слои разбиты так, чтобы вращаться отдельно через CSS: корпус, шарошки, брызги нефти.
2. **`bg.svg`** — фон: небо, силуэты вышек и заводов, дымящиеся трубы.
3. **Иконки покупок** — по одной на каждую покупку из `upgrades.json`, файл `icons/<id>.svg`. Для линеек (долота, насосы, яхты, машины) отдельные иконки по уровням с нарастающей «крутостью».
4. **`finale.svg`** — карикатура для финала: **толстый буржуй в цилиндре купается в монетах** (ванна, гора золота, сигара, довольная физиономия).
5. **`logo.svg`** — логотип «Империя обнуленного горизонта».
6. **Витрина богатства** — все предметы роскоши в том же стиле.
7. **Персонажи для событий:** император, министр, глава комитета, сенатор, подрядчик, конкурент (один шаблон с вариациями).

**Качество:**

- Проверь каждую SVG в размерах 64 px и 512 px: она должна читаться в обоих.
- Оптимизируй SVG (SVGO), но **не убирай `id` у слоёв**, нужных для анимации.
- Порядок отрисовки: `drill.svg` → иконки → фон → финал → остальное. Заглушек не оставляй: каждый коммит с графикой содержит законченные файлы.

### 9.1. Как заменить картинки и тексты (обязательный раздел README.md)

**Картинки.** Все лежат в `public/images/`. Чтобы заменить картинку, положи свою с тем же именем и форматом. Агент создаёт в README таблицу всех используемых файлов:

| Файл | Где используется | Рекомендуемый размер |
|---|---|---|
| `drill.svg` | центральная иконка скважины с долотом | квадрат, например 512×512 |
| `bg.svg` | фон игры | 1920×1080 |
| `icons/<id>.svg` | иконка покупки (имя = `id` из `upgrades.json`) | квадрат 128×128 |
| `finale.svg` | карикатура в финале | 1024×1024 |
| `logo.svg` | заставка | 512×256 |

**Тексты.**

- Все тексты интерфейса: `src/content/texts.json` (заголовки, кнопки, новости, подсказки).
- Названия и описания покупок: `src/content/upgrades.json`, поля `name` и `description`.
- Стихотворение для финала: `src/content/credits.txt`.
- Цены и баланс: `src/content/config.json` и `upgrades.json`.
- Правило: в коде не должно быть «зашитых» русских строк. Любой текст берётся из JSON по ключу.

## 10. План по этапам

После каждого этапа: тесты, обновление AGENTS.md, коммит и пуш.

**Этап 0. Каркас.** Vite + TS, структура папок, линтер, AGENTS.md, README, CI. Коммит: `chore: scaffold`.

**Этап 1. Ядро тапалки.** Состояние, тап через Pointer Events, нефтефаники на экране, тик, сохранение в localStorage, адаптивная вёрстка, звук тапа (Web Audio). Простая версия `drill.svg` с анимацией бурения. Коммит: `feat: core tap loop`.

**Этап 2. Экономика.** Доходы и расходы, налоги, чистый доход, все типы покупок, формулы цен. Юнит-тесты на формулы. Коммит: `feat: economy engine`.

**Этап 3. Контент-пайплайн.** Загрузка `upgrades.json`, `texts.json`, `config.json`. Вкладки и список покупок. Начальный набор 6–8 покупок в каждом разделе. Коммит: `feat: content loading and shop tabs`.

**Этап 4. Весь контент.** Заполнение всех покупок из раздела 6, новости, достижения. Коммит: `feat: full content`.

**Этап 5. События и гэмблы.** Кризисы с таймером и ×10, перезарядки, периодические месторождения, плавающая мировая цена нефти. Коммит: `feat: events and gambles`.

**Этап 6. Баланс.** Симулятор-бот, подбор `winCost` и множителей под 15–20 минут, тесты на длительность. Коммит: `feat: balance simulator`.

**Этап 7а. Весь SVG-арт** по арт-гайду (раздел 9). Коммит: `feat: art`.

**Этап 7б. Анимации, частицы, звуки событий, мобильная полировка.** Коммит: `feat: visual and audio polish`.

**Этап 8. Финал.** Покупка «Упыря-Абсолюта», катсцена, титры со стихотворением и карикатурой, статистика, перезапуск. Коммит: `feat: finale`.

**Этап 9. Релиз.** Дымовой тест Playwright на десктопном и мобильном профилях, деплой на GitHub Pages, финальная проверка README и AGENTS.md. Коммит и тег `v1.0`.

## 11. Критерии готовности

- Игра запускается командой `npm run dev` и собирается командой `npm run build`.
- Все покупки из раздела 6 присутствуют, обязательные формулировки сохранены.
- Игру можно пройти за 15–20 минут, это подтверждает тест-симулятор.
- Игра нормально работает и на десктопе, и на телефоне в браузере.
- Есть звук тапа и основных событий, с кнопкой отключения.
- Вся графика нарисована в SVG в едином стиле, заглушек нет.
- Финал показывает стихотворение (если файл положен) и карикатуру.
- Любую картинку и любой текст можно заменить без правки кода, по инструкции из README.
- AGENTS.md актуален, история коммитов отражает этапы.
