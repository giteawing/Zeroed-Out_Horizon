# Империя обнуленного горизонта

Браузерная экономическая игра про нефтяную империю. Развивай скважины и
производственное оборудование, управляй потоками нефти, получай **нефтефаники**,
покупай политику, технику и роскошь — и накопи на
**Магистральный Насос «Упырь-Абсолют»**, чтобы получить полный контроль.

Сатира, крупные мультяшные картинки, звук. Игра сделана под десктоп.
Прохождение — **15–20 минут**. Никакой крипты, кошельков и внешних сервисов:
сохранение лежит в `localStorage`.

> Исходное техническое задание сохранено в архиве
> [`docs/archive/TZ.md`](docs/archive/TZ.md) — это история требований, а не
> действующая спецификация. Внутренние договорённости и подсказки для
> разработки — в [`AGENTS.md`](AGENTS.md).

## Запуск

Нужен Node.js >=22.13.0.

```bash
npm install
npm run dev        # http://localhost:5173 — дев-сервер
npm run build      # сборка в dist/
npm run preview    # посмотреть собранную версию
```

### Тесты

```bash
npm run lint       # ESLint: забытые промисы, выражения без действия, any в обход типов
npm test           # экономика, движок, регрессии, контент, баланс и DOM
npm run test:e2e   # Playwright: только Desktop Chrome (поддержка телефонов убрана)
```

Для e2e один раз нужно поставить браузер:

```bash
npx playwright install chromium
```

Если браузер Playwright скачать нельзя, подойдёт любой свой Chromium:
`E2E_CHROMIUM_PATH=/путь/к/chromium npm run test:e2e` (дополнительные флаги —
в `E2E_CHROMIUM_ARGS`).

### Прочие команды

```bash
npm run art                          # создать недостающие иконки, пересобрать фон, лого, финал
npm run art:force                    # перезаписать иконки из генератора (сотрёт ручные правки)
npx tsx scripts/balance-report.ts    # таблица баланса по профилям игрока
npx tsx scripts/auto-balance.ts      # отчёт по подбору цен (с --write — записать)
```

## Как играть

**Сырая нефть добывается непрерывно** скважинами и производственным оборудованием.
Нефтефаники (₦) появляются только после продажи сырья или нефтепродуктов.

1. **Начните добычу.** В новой партии уже работает базовая скважина с дебитом
   8 т/с. «Пробурить скважину» — лотерея: обычная даёт 8–10 т/сут, хорошая —
   около 60, уникальная — сотни и тысячи тонн в сутки. Шансы классов — 70 / 25 / 5 %.
   «Отжать месторождение у конкурентов» и реприватизация тоже дают скважины.
   **Игровые сутки длятся 1 реальную секунду** (`config.oil.wells.secondsPerDay`),
   поэтому 8 т/сут — это 8 т/с. Со временем дебит падает до заданного минимума
   (`config.oil.wells.decline`), поэтому полезно развивать месторождение и технику.
2. **Настройте маршруты сырья.** В правой панели укажите поток в т/с отдельно
   для экспорта сырой нефти, переработки и внутреннего рынка. В режиме
   **«Авто»** направления делят доступный остаток по выручке с тонны сырья:
   у экспорта и внутреннего рынка это цена сырья, у НПЗ — 85 % от цены
   нефтепродуктов на том рынке, который их ещё примет
   (`config.oil.refineryYield`). На склад НПЗ работает в последнюю очередь.
   Фиксированное значение резервирует указанный объём, а остальные
   автоматические направления делят то, что осталось. Кнопка «Макс.» ставит
   предельный объём направления. Суммарная подача не может быть выше текущей
   добычи.
3. **Следите за мощностями.** Экспорт ограничен трубопроводами, железной дорогой
   и морскими терминалами; переработка — мощностью НПЗ, рынком нефтепродуктов
   и свободной ёмкостью нефтебаз; внутренний рынок — собственной пропускной
   способностью. Максимумы пересчитываются после строительства и изменения
   дебита. Нельзя задать поток выше доступной физической мощности.
   Покупки вкладки «Сбыт» с процентом за уровень расширяют свой рынок и
   заодно умножают добычу: считается больший из двух итогов — по внутреннему
   рынку или по экспорту (со всеми договорами — до ×25,8; в панели это строка
   «множитель от договоров»). У добычи есть потолок — 10 млн т/с
   (`config.oil.maxProductionPerSecond`): когда он достигнут, в строке
   «производство» появляется пометка «потолок», и покупки, увеличивающие
   добычу, больше ничего не прибавляют.
4. **Расширяйте хранилища и логистику.** Сырая нефть накапливается в резервуарах
   до отгрузочного окна. При переполнении выполняется досрочная отправка за
   фактически накопленное время. Нефтебазы хранят нефтепродукты, ранние цистерны
   увеличивают склад сырой нефти. Излишки без рынка или свободного склада
   разливаются и штрафуются.
5. **Развивайте бригаду.** Геонавигатор, геолог, операторы установки, инженер и
   буровая бригада-стахановцы вместе усиливают непрерывную добычу. Скважины
   и производственное оборудование продолжают работать без нажатий.
6. **Политика и налог.** Налог зависит **только от влияния и дружбы с
   чиновниками**: чем больше влияния, тем ниже ставка, и она никогда не
   «прыгает» случайно. Сауна с главой «комитета по промышленности», фонд и
   «закон о налоговом вычете для ресурсодобывающих олигархов» снижают налог
   дополнительно, а «министерство нефтяных ресурсов» приносит выплаты.
7. **Влияние** — отдельная валюта прогресса. Его дают свой человек в
   правительстве, газета, голоса в парламенте, должность главного секретаря
   и ЧВК; выплаты императора, сената, министерства и телеканал влияния не
   прибавляют (на карточке, которая его даёт, написано «+N влияния»). Без
   влияния чужие активы не отжать.
8. **Отжатия.** «Отжать нефтеперерабатывающий завод у конкурентов»
   и «Устроить реприватизацию месторождения со скважинами конкурента» стоят
   дешевле постройки, но требуют влияния и (для завода) своей ЧВК.
9. **Убыточный банк.** Купите банк «Последний кредит» — и через него можно
   проводить отмывание и уход от налогов. Это разовые операции с перезарядкой:
   деньги приходят мимо налоговой.
10. **Мировая цена.** В шапке видно, сколько сейчас стоит тонна —
   **в нефтефаниках за тонну** (например, «Мировая цена: ₦3/т»), а не в
   процентах. Полоса рядом показывает, где эта цена внутри коридора
   от −25 % до +28 % к базовой (`config.worldPrice.min/max`, сейчас
   0,75–1,28): зелёная — дорого, красная — дёшево.
11. **Экспортные акции.** «Контрабанда нефти заграницу» продаёт нефть со склада
   через экспорт при наличии мощности, а без неё — по контрактной цене. Как
   обычная отгрузка и трубопровод, акция проходит расходы и налог на прибыль.
12. **Откуда деньги.** Кроме продажи нефти, деньги приносят периодические
   выплаты покупок, кнопки-действия, проценты на остаток счёта (ставка растёт
   с влиянием), топливный демпфер и вывоз капитала. Периодические выплаты,
   выигрыши рисковых схем и операции убыточного банка приходят мимо налога и
   расходов; всё остальное проходит общую кассу. Подробности — в окне
   «Правила» и в [`docs/ECONOMY.md`](docs/ECONOMY.md).
13. **Финал.** Накопите на «Упыря-Абсолюта» на вкладке **Цель** и получите
   «Насос-Гигант» уровня 5 и «Умную скважину» уровня 3.

**Раскладка — два столбца.** Слева большой столбец с магазином и вкладками.
Справа — статистика, управление тремя потоками сырья, журнал операций и
статус производственной системы. Игра сделана под десктоп: мобильная вёрстка
убрана по решению заказчика.

**В магазине видно все покупки вкладки, включая закрытые.** Заблокированная
карточка не исчезает: она приглушена, обведена красным, кнопка неактивна,
а под ценой красным написано условие — «Нужно заработать ₦40»,
«Нужно: «Лопастное долото» (уровень 3)», «Нужно влияние не меньше 12».
Так сразу понятно, что и зачем покупать следующим.

Игра сохраняется сама. Если закрыть вкладку, при возвращении начислится
офлайн-доход — но не больше чем за 5 минут. Пока открыт стартовый экран,
игра стоит: добыча, продажи и автосохранение начинаются после кнопки
«Начать» или «Продолжить».

Сохранение одно на все вкладки браузера, поэтому игра идёт только в одной.
Вторая вкладка показывает «Игра уже открыта в другой вкладке» и ждёт: когда
первая закрыта, вторая сама продолжает с её сохранения.

### Инженерное меню (только в dev-сборке)

Пункт 🛠 в меню ☰ открывает инженерное меню — читерскую панель, чтобы не
гриндить 15 минут ради проверки финала. Он есть только при запуске
`npm run dev`: в production-сборке (`npm run build`, GitHub Pages) пункта
нет, игрок до панели добраться не может.

| Кнопка | Что делает |
|---|---|
| «Добавить 1 трлн ₦» | начисляет триллион нефтефаников |
| «Купить «Упырь-Абсолют»» | мгновенно покупает финальный насос и запускает титры |
| «Открыть все покупки» | снимает требования по деньгам и влиянию со всех покупок |

Всё сразу пишется в сохранение. Закрывается кнопкой «Закрыть» или `Esc`.

## Как заменить контент (без правки кода)

Всё содержимое игры лежит в данных. Кода касаться не нужно.

### Картинки

Все изображения — в `public/images/`. Чтобы заменить, положите свой файл
с тем же именем и в том же формате (SVG). Если кладёте PNG/JPG — поменяйте
расширение в соответствующем поле или в `icon` покупки.

| Файл | Где используется | Рекомендуемый размер |
|---|---|---|
| `bg.svg` | фон игры | 1920×1080 |
| `logo.svg` | заставка и шапка | 512×256 (сейчас 660×330) |
| `finale.svg` | карикатура в финале (буржуй в ванне) | 1024×1024 |
| `icons/<id>.svg` | иконка покупки, имя = `icon` из `upgrades.json` | квадрат 128×128 |

### Тексты

| Что | Файл |
|---|---|
| Заголовки, кнопки, подсказки, новости, достижения, единицы измерения | `src/content/texts.json` |
| Названия и описания покупок | `src/content/upgrades.json` (поля `name`, `description`) |
| Стихотворение для титров | `src/content/credits.txt` |
| Цены, налоги, `winCost`, офлайн-потолок | `src/content/config.json` |
| Экономика нефти: цена тонны, ёмкость склада, каналы сбыта, состав бригады | `src/content/config.json` → секция `oil` |

Названия покупок с пометкой `"tag": "strict"` — это формулировки из ТЗ,
их лучше не менять.

### Стихотворение для титров

По требованию ТЗ текст стихотворения **не вставлен по памяти**. Положите
текст Демьяна Бедного «Капитал» из открытого источника в
`src/content/credits.txt` — он появится в титрах. Пока файл содержит
заглушку, игра честно показывает «Здесь будет стихотворение.»

### Звук

Звуки не файлы, а синтез на Web Audio API (`src/audio/sound.ts`): касса при
покупке, сирена на события, фанфары на победу. Чтобы заменить звук —
отредактируйте методы `purchase`, `event`, `fanfare` или положите CC0-файлы
в `public/audio/` и проигрывайте их оттуда (тогда источник и лицензию укажите здесь).
Переключатель 🔊/🔇 есть в меню ☰ и в настройках; состояние сохраняется.

### Баланс

Баланс проверяется детерминированными профилями и отдельным оптимизатором
повторяемых действий. Целевой диапазон — 12–25 минут, обычный профиль
ориентирован на 15–20 минут. Точные результаты зависят от текущей экономики
и публикуются свежим `npm run balance:report`, а не хранятся в README.

```bash
npm run balance
npm run balance:report             # текущая цена для всех профилей
npx tsx scripts/balance-report.ts --grid # полная матрица цен
npx tsx scripts/tune-2d.ts          # отчёт; запись требует --write --i-know
npx tsx scripts/tune-scale.ts       # отчёт; запись требует --write --i-know
```

Ключевые параметры баланса:

- `config.oil.channels` — цена и пропускная способность рынков;
- `config.oil.baseCapacity` — ёмкость резервуаров сырой нефти;
- `config.winCost` и `win_pump.baseCost` — согласованная цена финальной цели;
- `config.oil.wells.secondsPerDay` и `decline` — скорость и падение дебита.

Скрипты изменения баланса требуют обоих флагов `--write --i-know`.
Перед запуском сохраните исходные JSON и проверьте diff. Одноразовая
`scripts/migrate-oil-model.ts` отключена, поскольку она восстанавливала
устаревший каталог покупок.

## Деплой

### GitHub Pages (автоматически)

В репозитории есть workflow `.github/workflows/deploy.yml`: после успешного
CI на `main` он собирает игру и публикует `dist/` на GitHub Pages. Если CI
упал или за это время в `main` появился более новый коммит, публикация
пропускается. В настройках репозитория выберите
**Settings → Pages → Source: GitHub Actions**.

Сборка использует относительные пути, поэтому работает и из подпапки
(`username.github.io/repository/`).

### Любой статический хостинг

```bash
npm run build
# выложить содержимое dist/ (Netlify, Vercel, Cloudflare Pages, nginx…)
```

## Что внутри

- **Магазин:** техника, политика, сбыт, роскошь и финальная цель;
  в магазине видны все, закрытые — с красной причиной.
- **Улучшения с историей:** долото, насос, забойный двигатель, буровой раствор
  и ГРП — это одна покупка на всё прохождение, но **название меняется
  с каждым уровнем** («Долото «Буравчик-1»» → «…Шарошка» → «…Терминатор»).
- **Банк с масштабом:** «убыточный банк» покупается один раз, после него
  открываются «Увеличение масштабов деятельности банка» (на уровнях 2, 4 и 6
  открываются операции), «заставить всех сотрудников получать зарплату через
  банк» (меньше издержек) и три операции — спрятать транш, уйти от налогов,
  отмыть деньги. Каждый уровень банка усиливает их выплаты.
- **Реприватизация:** за влияние и деньги игрок получает случайное число
  скважин, но их стоимость всегда в **5–10 раз больше** уплаченного.
- **Панель империи:** непрерывная добыча (т/с), потоки сырой нефти, скважины,
  прибыль в секунду, стоимость активов и построенные НПЗ, нефтебазы, АЗС,
  резервуары, трубопроводы, железнодорожные и морские терминалы.
- **Нефтяная экономика:** добыча → управляемая маршрутизация сырья → экспорт,
  внутренний рынок или НПЗ → реализация нефтепродуктов. Мощности рынков,
  транспорта, НПЗ и складов ограничивают доступные объёмы.
- **Влияние империи** как отдельная валюта прогресса: дружба с императором,
  газета, парламент и ЧВК открывают отжатия чужих активов.
- **ЧВК, убыточный банк, реприватизация:** своя охрана усиливает влияние и
  удешевляет отжатия, банк проводит отмывание и уход от налогов.
- **Журнал операций** в правой панели: каждая сделка с тоннами, ценой и суммой.
- **16 достижений**, лента новостей из 70+ заголовков: новости выходят по
  событиям, а фоновые — только о том, что у игрока уже есть (о банке — после
  банковской операции, о ЧВК — после найма охраны).
- **Игровые механики:** непрерывная добыча, маршрутизация сырья, ёмкость
  складов, каналы сбыта, производственные множители, налоги и расходы,
  периодические бонусы, разовые выплаты, рисковые схемы, влияние и роскошь.
- **Инженерное меню** 🛠 (только в dev-сборке): «+1 трлн», мгновенный финал,
  открытие всех покупок.
- **Офлайн-доход** с потолком 5 минут.
- **Графика:** всё нарисовано в SVG в едином стиле (толстая обводка, палитра из
  8 цветов). Для покупок есть отдельные SVG-иконки, в том числе для ЧВК,
  банка, отмывания и реприватизации.
