# Империя обнуленного горизонта

Браузерная кликер-тапалка про нефтяную империю. Тапай по долоту, получай
**нефтефаники**, покупай политику, технику и роскошь — и накопи на
**Магистральный Насос «Упырь-Абсолют»**, чтобы получить полный контроль.

Сатира, крупные мультяшные картинки, звук. Игра сделана под десктоп.
Прохождение — **15–20 минут**. Никакой крипты, кошельков и внешних сервисов:
сохранение лежит в `localStorage`.

> Техническое задание, по которому сделана игра, сохранено в
> [`docs/TZ.md`](docs/TZ.md). Внутренние договорённости и подсказки для
> разработки — в [`AGENTS.md`](AGENTS.md).

## Запуск

Нужен Node.js >=22.12.0.

```bash
npm install
npm run dev        # http://localhost:5173 — дев-сервер
npm run build      # сборка в dist/
npm run preview    # посмотреть собранную версию
```

### Тесты

```bash
npm test           # экономика, движок, регрессии, контент, баланс и DOM
npm run test:e2e   # Playwright: только Desktop Chrome (поддержка телефонов убрана)
```

Для e2e один раз нужно поставить браузер:

```bash
npx playwright install chromium
```

### Прочие команды

```bash
npm run art                          # перегенерировать SVG (иконки, фон, лого, финал)
npx tsx scripts/balance-report.ts    # таблица баланса по профилям игрока
npx tsx scripts/auto-balance.ts      # отчёт по подбору цен (с --write — записать)
```

## Как играть

Главное отличие от обычных кликеров: **тап добывает нефть, а не деньги.**
Нефтьфаники (₦) появляются только тогда, когда нефть продана.

1. **Качайте нефть.** Тап по долоту добавляет тонны в резервуары.
2. **Бурите скважины.** «Пробурить скважину» — лотерея, как в жизни: дебит
   выпадает случайно. Обычная скважина даёт 8–10 т/сут, хорошая — около 60,
   уникальная — сотни и тысячи тонн в сутки. Всего классов три, шансы 70 / 25 / 5 %.
   «Отжать месторождение у конкурентов» и «реприватизация» тоже дают скважину,
   только вместе с чужим оборудованием. Скважины качают сами: дебит всех
   скважин складывается, и нефть идёт в резервуары без тапов.
   **Игровые сутки длятся 1 реальную секунду** (`config.oil.wells.secondsPerDay`),
   поэтому 8 т/сут — это 8 т/с: иначе игра стояла бы на месте.
   Со временем дебит падает — пласт истощается, но не сильно: к концу партии
   остаётся около 70 % от стартового (`config.oil.wells.decline`:
   `minFactor 0.7`, `halfLifeSeconds 1800`). Падение подстёгивает докупать
   скважины и технику, но не наказывает за долгую игру.
3. **Продавайте нефть.** Сбыт идёт сам по трём каналам, от дорогого к дешёвому:
   - **переработка** (НПЗ) — самая высокая цена за тонну;
   - **экспорт** (трубы, танкеры, терминалы) — средняя цена;
   - **контракты** — самая низкая, зато берут любой объём и продают всегда.

   Нефть сначала уходит в дорогие каналы, а остаток — в контракты. Поэтому
   выгодно строить НПЗ и экспорт: без них вся нефть уходит за бесценок.
4. **Расширяйте резервуары.** При переполнении сначала выполняется срочная
   отгрузка за реально накопленное время. Если рынки не успевают принять
   нефть, излишек разливается и штрафуется. Нефтебаза хранит нефтепродукты,
   а ранние цистерны увеличивают склад сырой нефти.
5. **Наймите бригаду.** Геонавигатор, геолог, операторы установки, инженер и
   буровая бригада-стахановцы вместе включают **автодобычу**: нефть качается
   сама, вдвое быстрее, и можно уйти за чаем.
6. **Политика и налог.** Налог зависит **только от влияния и дружбы с
   чиновниками**: чем больше влияния, тем ниже ставка, и она никогда не
   «прыгает» случайно. Сауна с главой «комитета по промышленности», фонд и
   «закон о налоговом вычете для ресурсодобывающих олигархов» снижают налог
   дополнительно, а «министерство нефтяных ресурсов» приносит выплаты.
7. **Влияние** — отдельная валюта прогресса. Оно растёт от политических
   покупок, газеты, парламента, императора и ЧВК. Без влияния чужие активы
   не отжать.
8. **Отжатия.** «Отжать нефтеперерабатывающий завод у конкурентов»
   и «Устроить реприватизацию месторождения со скважинами конкурента» стоят
   дешевле постройки, но требуют влияния и (для завода) своей ЧВК.
9. **Убыточный банк.** Купите банк «Последний кредит» — и через него можно
   проводить отмывание и уход от налогов. Это разовые операции с перезарядкой:
   деньги приходят мимо налоговой.
10. **Мировая цена.** В шапке видно, сколько сейчас стоит тонна —
   **в нефтефаниках за тонну** (например, «Мировая цена: ₦3/т»), а не в
   процентах. Полоса рядом показывает, где эта цена внутри коридора
   ±30 % (`config.worldPrice.min/max`): зелёная — дорого, красная — дёшево.
11. **Экспортные акции.** «Контрабанда нефти заграницу» продаёт нефть со склада
   через экспорт при наличии мощности, а без неё — по контрактной цене. Как
   обычная отгрузка и трубопровод, акция проходит расходы и налог на прибыль.
12. **Финал.** Накопите на «Упыря-Абсолюта» на вкладке **Цель** и получите
   «Насос-Гигант» уровня 5 и «Умную скважину» уровня 3.

**Раскладка — два столбца.** Слева большой столбец с магазином и вкладками
(Техника, Сбыт, Политика, Роскошь, Цель). Справа узкий столбец: сверху таблица
доходов и расходов, под ней журнал операций, внизу долото для тапов. Игра
сделана под десктоп: мобильная вёрстка убрана по решению заказчика.

**В магазине видно все покупки вкладки, включая закрытые.** Заблокированная
карточка не исчезает: она приглушена, обведена красным, кнопка неактивна,
а под ценой красным написано условие — «Нужно заработать ₦40»,
«Нужно: «Лопастное долото» (уровень 3)», «Нужно влияние не меньше 12».
Так сразу понятно, что и зачем покупать следующим.

Игра сохраняется сама. Если закрыть вкладку, при возвращении начислится
офлайн-доход — но не больше чем за 5 минут.

### Инженерное меню (для проверки)

Кнопка 🛠 в шапке открывает инженерное меню — читерскую панель, чтобы не
гриндить 15 минут ради проверки финала:

| Кнопка | Что делает |
|---|---|
| «Добавить 1 трлн ₦» | начисляет триллион нефтефаников |
| «Купить «Упырь-Абсолют»» | мгновенно покупает финальный насос и запускает титры |
| «Открыть все покупки» | снимает требования по деньгам и влиянию со всех покупок |

Всё сразу пишется в сохранение. Закрывается кнопкой «Закрыть» или `Esc`.
Меню сделано для разработки и остаётся в игре — в обычной игре его можно
просто не открывать.

## Как заменить контент (без правки кода)

Всё содержимое игры лежит в данных. Кода касаться не нужно.

### Картинки

Все изображения — в `public/images/`. Чтобы заменить, положите свой файл
с тем же именем и в том же формате (SVG). Если кладёте PNG/JPG — поменяйте
расширение в соответствующем поле или в `icon` покупки.

| Файл | Где используется | Рекомендуемый размер |
|---|---|---|
| `drill.svg` | центральная скважина с долотом | квадрат 512×512 |
| `bg.svg` | фон игры | 1920×1080 |
| `logo.svg` | заставка и шапка | 512×256 (сейчас 660×330) |
| `finale.svg` | карикатура в финале (буржуй в ванне) | 1024×1024 |
| `icons/<id>.svg` | иконка покупки, имя = `icon` из `upgrades.json` | квадрат 128×128 |

> В центральной картинке `drill.svg` есть слои с `id`: `cones` (шарошки,
> они вращаются), `btn-body`, `splashes`, `casing`, `rig`, `strata`. Если
> рисуете свою скважину — сохраните эти `id`, иначе перестанет работать
> анимация бурения.

### Тексты

| Что | Файл |
|---|---|
| Заголовки, кнопки, подсказки, новости, достижения, единицы измерения | `src/content/texts.json` |
| Названия и описания покупок | `src/content/upgrades.json` (поля `name`, `description`) |
| Стихотворение для титров | `src/content/credits.txt` |
| Цены, налоги, `winCost`, офлайн-потолок | `src/content/config.json` |
| Экономика нефти: цена тонны, ёмкость склада, каналы сбыта, состав бригады | `src/content/config.json` → секция `oil` |

Названия покупок с пометкой `"tag": "strict"` — это формулировки из ТЗ,
их лучше не менять.

### Стихотворение для титров

По требованию ТЗ текст стихотворения **не вставлен по памяти**. Положите
текст Демьяна Бедного «Капитал» из открытого источника в
`src/content/credits.txt` — он появится в титрах. Пока файл содержит
заглушку, игра честно показывает «Здесь будет стихотворение.»

### Звук

Звуки не файлы, а синтез на Web Audio API (`src/audio/sound.ts`): тап
(4 вариации высоты), касса при покупке, сирена на события, фанфары на победу.
Чтобы заменить звук — отредактируйте соответствующий метод (`tap`,
`purchase`, `event`, `fanfare`) или положите CC0-файлы в `public/audio/`
и проигрывайте их оттуда (тогда источник и лицензию укажите здесь).
Кнопка 🔊/🔇 есть в шапке и в настройках; состояние сохраняется.

### Баланс

Баланс проверяется детерминированными профилями и отдельным оптимизатором
повторяемых действий. Целевой диапазон — 12–25 минут, обычный профиль
ориентирован на 15–20 минут. Точные результаты зависят от текущей экономики
и публикуются свежим `npm run balance:report`, а не хранятся в README.

```bash
npm run balance
npm run balance:report
npx tsx scripts/tune-2d.ts          # отчёт; запись требует --write --i-know
npx tsx scripts/tune-scale.ts       # отчёт; запись требует --write --i-know
```

Ключевые параметры баланса:

- `config.oil.channels` — цена и пропускная способность рынков;
- `config.oil.baseCapacity` — ёмкость резервуаров сырой нефти;
- `config.winCost` и `win_pump.baseCost` — согласованная цена финальной цели;
- `config.oil.wells.secondsPerDay` и `decline` — скорость и падение дебита.

Скрипты изменения баланса требуют обоих флагов `--write --i-know`.
Перед запуском сохраните исходные JSON и проверьте diff. Одноразовая
`scripts/migrate-oil-model.ts` отключена, поскольку она восстанавливала
устаревший каталог покупок.

## Деплой

### GitHub Pages (автоматически)

В репозитории есть workflow `.github/workflows/deploy.yml`: на каждый пуш
в `main` он собирает игру и публикует `dist/` на GitHub Pages.
В настройках репозитория выберите **Settings → Pages → Source: GitHub Actions**.

Сборка использует относительные пути, поэтому работает и из подпапки
(`username.github.io/repository/`).

### Любой статический хостинг

```bash
npm run build
# выложить содержимое dist/ (Netlify, Vercel, Cloudflare Pages, nginx…)
```

## Что внутри

- **:** техника, политика, сбыт, роскошь и финальная цель;
  в магазине видны все, закрытые — с красной причиной.
- **Улучшения с историей:** долото, насос, забойный двигатель, буровой раствор
  и ГРП — это одна покупка на всё прохождение, но **название меняется
  с каждым уровнем** («Долото «Буравчик-1»» → «…Шарошка» → «…Терминатор»).
- **Банк с масштабом:** «убыточный банк» покупается один раз, после него
  открываются «Увеличение масштабов деятельности банка» (на уровнях 2, 4 и 6
  открываются операции), «заставить всех сотрудников получать зарплату через
  банк» (меньше издержек) и три операции — спрятать транш, уйти от налогов,
  отмыть деньги. Каждый уровень банка усиливает их выплаты.
- **Реприватизация:** за влияние и деньги игрок получает случайное число
  скважин, но их стоимость всегда в **5–10 раз больше** уплаченного.
- **Панель империи:** добыча в сутки (т/сут), скважины, прибыль в секунду,
  стоимость всех активов, внутренняя и экспортная цена тонны, а также
  сколько построено НПЗ, нефтебаз, АЗС и трубопроводов.
- **Нефтяная экономика:** добыча → три канала сбыта → деньги. Склад с
  переполнением, автодобыча от бригады из пяти сотрудников, плавающая мировая
  цена (±30 %) и рыночные акции.
- **Влияние империи** как отдельная валюта прогресса: дружба с императором,
  газета, парламент и ЧВК открывают отжатия чужих активов.
- **ЧВК, убыточный банк, реприватизация:** своя охрана усиливает влияние и
  удешевляет отжатия, банк проводит отмывание и уход от налогов.
- **Журнал операций** под долотом: каждая сделка с тоннами, ценой и суммой.
- **16 достижений**, лента новостей из 70+ заголовков, реагирующая на события.
- **14 типов механик:** добыча за тап и в секунду, ёмкость склада, каналы
  сбыта, множители, налоги и расходы, периодические бонусы, разовые выплаты,
  рисковые схемы, влияние, роскошь.
- **Инженерное меню** 🛠: «+1 трлн», мгновенный финал, открытие всех покупок.
- **Офлайн-доход** с потолком 5 минут.
- **Графика:** всё нарисовано в SVG в едином стиле (толстая обводка, палитра из
  8 цветов), включая  покупок — в том числе отдельные иконки для
  ЧВК, банка, отмывания и реприватизации.
